# Security Policy

This repository contains educational reference implementations, declarative policy templates, and presentation materials for regulated AI governance (**RBI FREE-AI**, **EU AI Act**, and **RBI Draft MRM Guidance**).

## Important Notice
- All sample datasets, actor IDs (`user-1`, `advisor-7`), and incident reports (`INC-2026-0042`) are **100% synthetic**.
- Never commit real customer PII, PAN/Aadhaar numbers, API keys, or proprietary bank data to this repository.

## Reporting a Vulnerability or Control Bypass
If you find a policy bypass in `code/gate/`, a hash-chain flaw in `code/audit/`, or a security issue in `index.html`:
- Open a GitHub Security Advisory on this repository, or
- Reach out directly via https://pratikdhanave.com / https://linkedin.com/in/pratikdhanave.
